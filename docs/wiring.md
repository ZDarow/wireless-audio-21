# Подключение (wiring) Wireless Audio 2.1

> Версия документа: 1.2 (11.08.2026). Все пины — по умолчанию из
> `config.example.env`. Платформа — **ESP32-S3**: GPIO22–25 невалидны
> (внутренний SPI-флеш), I2S используется на GPIO4/5/6.
> Усилитель — **TPA3110 XH-A232** (класс D, аналоговый вход) — требует ЦАП
> между ESP32 и усилителем. Цепочка: ESP32 I2S → ЦАП PCM5102A → TPA3110 → динамик.
> При изменении GPIO не забудьте перегенерировать
> конфиг: `python3 scripts/generate_config.py config.env`.

## 0. ЦАП → усилитель (TPA3110 XH-A232)

TPA3110 XH-A232 — стереоусилитель класса D на TPA3110D2, **вход только
аналоговый** (линейный). I2S с ESP32 подавать напрямую нельзя — ставится ЦАП
PCM5102A (I2S→линейный стерео). Схема ЦАП → усилитель (одинакова для мастера
и сателлитов):

```
PCM5102A                    TPA3110 XH-A232
LRCK ───────────┐
BCK  ───────────┼─┤ (не используются при аналоговом выходе)
DIN  ───────────┘
LOUT ────────────────────────► L-IN   (левый канал)
ROUT ────────────────────────► R-IN   (правый канал)
GND  ────────────────────────► GND (входной разъём)
5V  ──► (питание 3.3/5 В, VIN)
```

> На XH-A232 входной разъём: 4 контакта — L-IN, GND, R-IN, GND.
> Усилитель имеет свои регуляторы громкости (потенциометры) — выставить
> на максимум/среднее, громкость управляется из Web UI мастера.

## 1. Мастер-узел (сабвуфер)

```
                    ESP32-S3 DevKit
                 ┌──────────────┐
  USB 5V ────────┤ 5V           │
  GND  ──────────┤ GND          │
                 │              │
  ЦАП (PCM5102A) │              │
  BCK  ←─────────┤ GPIO4 (BCK)  │
  WS   ←─────────┤ GPIO5 (WS)   │
  DIN  ←─────────┤ GPIO6 (DIN)  │
  GND  ←─────────┤ GND          │
                 └──────────────┘

PCM5102A LOUT/ROUT → TPA3110 XH-A232 L-IN / R-IN → динамик сабвуфера
```

Сабвуфер: I2S → ЦАП (PCM5102A) → усилитель TPA3110 XH-A232 → динамик 4–8 Ом.
Для сабвуфера оба входа TPA3110 можно подать один и тот же (моно) сигнал
(LPF-выход мастера).

## 2. Сателлит (левый / правый) — идентично

```
                    ESP32-S3 DevKit
                 ┌──────────────┐
  USB 5V ────────┤ 5V           │
  GND  ──────────┤ GND          │
                 │              │
  ЦАП (PCM5102A) │              │
  BCK  ←─────────┤ GPIO4 (BCK)  │
  WS   ←─────────┤ GPIO5 (WS)   │
  DIN  ←─────────┤ GPIO6 (DIN)  │
  GND  ←─────────┤ GND          │
                 └──────────────┘

PCM5102A LOUT/ROUT → TPA3110 XH-A232 L-IN / R-IN → динамик
```

Разница между левым и правым — только прошивка
(`-DAUDIO_SATELLITE_SIDE=0/1`), схема одинакова. Сателлит — моно (один канал):
подавать его на один из входов TPA3110 (L-IN или R-IN), второй оставить
свободным, либо раздвоить сигнал на оба входа.

## 3. Вариант с MAX98357A (усилитель класса D со встроенным ЦАП, I2S-вход)

Если усилитель заменён на MAX98357A, внешний ЦАП не нужен:

```
ESP32 GPIO4 (BCK)  →  MAX98357A BCLK
ESP32 GPIO5 (WS)   →  MAX98357A LRC
ESP32 GPIO6 (DIN)  →  MAX98357A DIN
5V (внешний)       →  MAX98357A VIN
GND (общий)        →  MAX98357A GND
MAX98357A + / -    →  динамик 4–8 Ом
```

> MAX98357A питается от 5 В и имеет встроенный ЦАП — внешний ЦАП не нужен.
> Общая земля с ESP32 обязательна.

## 4. Схема питания (рекомендуемая)

```
Блок 12В/3А (TPA3110 XH-A232, 12–24 В)
  ├── 12V ── TPA3110 XH-A232 (VCC)
  │   └── 12V → DC-DC 5В ── ESP32 (VIN/5V) и ЦАП PCM5102A (5V)
  └── GND ── общая земля (звезда): ESP32, ЦАП, усилитель
```

- **TPA3110 XH-A232**: питание 12–24 В постоянного тока (типично 12 В),
  пиковая мощность ~2×15 Вт при 12 В / 2×30 Вт при 24 В на 8 Ом.
  ESP32 и ЦАП питаются от отдельного 5 В (через DC-DC от той же шины
  12 В или от USB), чтобы усилитель не просаживал логику.
- Общая земля с ESP32 обязательна (звезда, одна точка).
- Конденсаторы: 100 нФ + 470 мкФ у каждого потребителя (ESP32, ЦАП, усилитель).

## 5. Таблица пинов (сводная)

| Пин ESP32-S3 | Сигнал | Куда | Примечание |
|---|---|---|---|
| GPIO4 | I2S BCK | ЦАП PCM5102A BCK | тактовая |
| GPIO5 | I2S WS | ЦАП PCM5102A LRCK | слово |
| GPIO6 | I2S DIN | ЦАП PCM5102A DIN | данные |
| GPIO21 | (OLED SDA) | — | этап 4 |
| GPIO18 | (OLED SCL) | — | этап 4 |
| GPIO32 | (ENC A) | — | этап 4 |
| GPIO33 | (ENC B) | — | этап 4 |
| GPIO34 | (ENC BTN) | — | этап 4, вход-only |
| 5V | питание | USB/DC-DC | |
| GND | земля | общая | |

Аналоговые линии (после ЦАП):

| Источник | Сигнал | Куда |
|---|---|---|
| PCM5102A | LOUT | TPA3110 XH-A232 L-IN |
| PCM5102A | ROUT | TPA3110 XH-A232 R-IN |
| PCM5102A | GND | TPA3110 входной GND |
| 12 В | VCC | TPA3110 XH-A232 VCC |

> GPIO22–25 на ESP32-S3 недоступны (подключены к внутреннему SPI-флешу) —
> не используйте их ни для I2S, ни для OLED.

## 6. Проверка подключения

1. Визуально: BCK/WS/DIN не перепутаны (иначе — шум/тишина).
2. `pio device monitor` → у мастера `status`; у сателлита
   `master_online: yes` при передаче.
3. Если звука нет:
   - проверить общую землю;
   - проверить питание усилителя (12 В на XH-A232);
   - проверить регуляторы громкости на XH-A232 (не выкручены в ноль);
   - проверить громкость (`volume 80`) и отсутствие mute.
