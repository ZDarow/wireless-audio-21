# Подключение (wiring) Wireless Audio 2.1

> Версия документа: 1.0 (10.08.2026). Все пины — по умолчанию из
> `config.example.env`. При изменении GPIO не забудьте перегенерировать
> конфиг: `python3 scripts/generate_config.py config.env`.

## 1. Мастер-узел (сабвуфер)

```
                    ESP32 DevKit
                 ┌──────────────┐
  USB 5V ────────┤ 5V           │
  GND  ──────────┤ GND          │
                 │              │
  ЦАП/усилитель  │              │
  сабвуфера:     │              │
  BCK  ←─────────┤ GPIO26 (BCK) │
  WS   ←─────────┤ GPIO25 (WS)  │
  DIN  ←─────────┤ GPIO22 (DIN) │
  GND  ←─────────┤ GND          │
                 └──────────────┘
```

Сабвуфер: I2S → ЦАП (PCM5102A) → усилитель (PAM8403) → динамик 4–8 Ом.

## 2. Сателлит (левый / правый) — идентично

```
                    ESP32 DevKit
                 ┌──────────────┐
  USB 5V ────────┤ 5V           │
  GND  ──────────┤ GND          │
                 │              │
  ЦАП/усилитель  │              │
  динамика:      │              │
  BCK  ←─────────┤ GPIO26 (BCK) │
  WS   ←─────────┤ GPIO25 (WS)  │
  DIN  ←─────────┤ GPIO22 (DIN) │
  GND  ←─────────┤ GND          │
                 └──────────────┘
```

Разница между левым и правым — только прошивка
(`-DAUDIO_SATELLITE_SIDE=0/1`), схема одинакова.

## 3. Вариант с MAX98357A (усилитель класса D, без внешнего ЦАП)

```
ESP32 GPIO26 (BCK)  →  MAX98357A BCLK
ESP32 GPIO25 (WS)   →  MAX98357A LRC
ESP32 GPIO22 (DIN)  →  MAX98357A DIN
5V (внешний)        →  MAX98357A VIN
GND (общий)         →  MAX98357A GND
MAX98357A + / -     →  динамик 4–8 Ом
```

> MAX98357A питается от 5 В и имеет встроенный ЦАП — внешний ЦАП не нужен.
> Общая земля с ESP32 обязательна.

## 4. Схема питания (рекомендуемая)

```
Блок 5В/2А
  ├── 5V ── ESP32 (VIN/5V)
  ├── 5V ── MAX98357A (или усилитель)
  └── GND ── общая земля (звезда)
```

- Если усилитель требует 12 В — отдельный блок, земля соединяется с ESP32.
- Конденсаторы: 100 нФ + 470 мкФ у каждого потребителя.

## 5. Таблица пинов (сводная)

| Пин ESP32 | Сигнал | Куда | Примечание |
|---|---|---|---|
| GPIO26 | I2S BCK | ЦАП/усилитель BCK/BCLK | тактовая |
| GPIO25 | I2S WS | ЦАП/усилитель LRC/LRCK | слово |
| GPIO22 | I2S DIN | ЦАП/усилитель DIN | данные |
| GPIO21 | (OLED SDA) | — | этап 4 |
| GPIO22 | (OLED SCL) | — | этап 4, конфликт с I2S DIN! |
| GPIO32 | (ENC A) | — | этап 4 |
| GPIO33 | (ENC B) | — | этап 4 |
| GPIO34 | (ENC BTN) | — | этап 4, вход-only |
| 5V | питание | USB/стабилизатор | |
| GND | земля | общая | |

## 6. Проверка подключения

1. Визуально: BCK/WS/DIN не перепутаны (иначе — шум/тишина).
2. `pio device monitor` → у мастера `status`; у сателлита
   `master_online: yes` при передаче.
3. Если звука нет:
   - проверить общую землю;
   - проверить питание усилителя;
   - проверить, что GPIO22 не занят OLED (конфликт);
   - проверить громкость (`volume 80`) и отсутствие mute.
