# Аппаратная часть Wireless Audio 2.1

> Версия документа: 1.4 (14.08.2026). GPIO соответствуют целевой плате
> ESP32-S3-DevKitC-1 N8R2 (8MB flash, без PSRAM). I2S переопределены через
> build_flags в `platformio.ini` (BCK=14, WS=13, DIN=12); в `config.env`
> дефолты — 4/5/6. GPIO22–25 на S3 невалидны (внутренний SPI-флеш).

## 1. Состав системы

| Узел | Плата | Назначение |
|---|---|---|
| Мастер | ESP32-S3-DevKitC-1 N8R2 (8MB, без PSRAM) | Приём Wi-Fi UDP PCM, DSP, раздача каналов, сабвуфер |
| Сателлит левый | ESP32-S3-DevKitC-1 N8R2 | Приём левого канала, вывод на динамик |
| Сателлит правый | ESP32-S3-DevKitC-1 N8R2 | Приём правого канала, вывод на динамик |

Роль и сторона задаются на этапе прошивки (см. `docs/architecture.md` §9).
В сателлитах допускается ESP32-WROOM-32E без PSRAM, если не требуется
сложная обработка (ТЗ §5.4).

## 2. Питание

- Мастер: 24 В → DC-DC 5 В (от шины RS-400W-24V) → ESP32-S3, OLED, энкодер
  (ТЗ §5.2). LC-фильтр по входу 5 В; цифровая и силовая земля — в одной точке.
- **TPA3110 XH-A232**: питание 12–24 В постоянного тока (типично 12 В),
  отдельная линия от блока 12 В (или от той же шины через DC-DC).
  ESP32 и ЦАП PCM5102A — от 5 В, чтобы усилитель не просаживал логику.
  Общая земля обязательна (звезда, одна точка).
- Суммарный ток: ESP32-S3 до ~500 мА (Wi-Fi активен). Усилители — по паспорту
  (TPA3110D2: ~2×15 Вт при 12 В / ~2×30 Вт при 24 В на 8 Ом, КПД ~90%).

## 3. I2S-выход (аудио)

Каждый узел использует один I2S-канал в режиме master TX, моно
(`I2S_CHANNEL_FMT_ONLY_LEFT`), 16 бит, 48000 Гц.

| Сигнал | GPIO по умолчанию | Описание |
|---|---|---|
| BCK (bit clock) | **4** | тактовая частота битов |
| WS (word select) | **5** | переключение каналов L/R |
| DATA_OUT | **6** | аудиоданные (последовательный) |

> GPIO22–25 на ESP32-S3 недоступны (внутренний SPI-флеш) — для I2S
> использовать только валидные пины (по умолчанию 4/5/6).

### Подключение к ЦАП/усилителю

Усилитель TPA3110 XH-A232 — **аналоговый** (L-IN/R-IN), поэтому между
ESP32 и ним обязателен ЦАП PCM5102A (I2S → линейный стерео):

```
ESP32 GPIO4 (BCK)  →  PCM5102A BCK
ESP32 GPIO5 (WS)   →  PCM5102A LRCK
ESP32 GPIO6 (DIN)  →  PCM5102A DIN
GND                →  PCM5102A GND
3.3/5 В            →  PCM5102A VIN

PCM5102A LOUT      →  TPA3110 XH-A232 L-IN
PCM5102A ROUT      →  TPA3110 XH-A232 R-IN
PCM5102A GND       →  TPA3110 входной GND
```

- **PCM5102A**: ЦАП I2S→линейный, питание 3.3–5 В, стерео LOUT/ROUT.
- **TPA3110 XH-A232**: усилитель класса D на TPA3110D2, питание 12–24 В,
  аналоговый вход (L-IN, GND, R-IN, GND), выходы L+/L- и R+/R- на динамики
  4–8 Ом; имеет потенциометры громкости на плате.
- **MAX98357A** (альтернатива): I2S-усилитель класса D со встроенным ЦАП,
  питание 5 В, выход напрямую на динамик — внешний ЦАП не нужен.
  Пины: BCLK, LRC, DIN, VIN, GND.

## 4. Wi-Fi (мастер)

- Модуль: встроенный Wi-Fi 2.4 GHz ESP32-S3 (b/g/n). Bluetooth Classic/A2DP
  на S3 отсутствует — аудио приходит по Wi-Fi UDP PCM со смартфона (ТЗ §6).
- Режимы: AP_DIRECT (мастер создаёт точку доступа `Audio21-Master`,
  канал 6, 20 МГц) или STA (подключение к домашней сети) — см. конфиг.
- Power save Wi-Fi отключается (для стабильного аудиопотока).

## 5. Опционально (этап 4 — OLED и энкодер)

Пины зарезервированы в конфигурации, но в MVP не используются:

| Сигнал | GPIO по умолчанию | Модуль |
|---|---|---|
| OLED SDA | **21** | SSD1306 (I2C) |
| OLED SCL | **18** | SSD1306 (I2C) |
| ENC A | **32** | энкодер KY-040 |
| ENC B | **33** | энкодер KY-040 |
| ENC BTN | **34** | кнопка энкодера |

> GPIO 34 — вход-only (без подтяжки). GPIO 21/18 — валидные пины S3,
> конфликтов с I2S (4/5/6) нет. GPIO22–25 не использовать (SPI-флеш).

## 6. Рекомендации по разводке

- Аудио-линии (BCK/WS/DIN) — короткие, экранированные от силовых.
- Питание усилителя — отдельно от ESP32, общая земля в одной точке
  (звезда), чтобы избежать фона 50 Гц.
- Развязка по питанию: керамика 100 нФ + электролит 100–470 мкФ у
  ESP32 и у усилителя.
- Антенна ESP32 — не ближе 1 см от металла и силовых проводов.

## 7. Проверка после сборки

1. `pio run -e master_s3_wifi -t upload` — прошить мастер.
2. `pio run -e satellite_s3_left -t upload` и `-e satellite_s3_right` — сателлиты.
3. `pio device monitor` — в консоли мастера `status`; у сателлитов
   `master_online: yes` при работающей передаче.
4. Web UI мастера: `http://<IP>/` (IP печатается при старте).
5. Проверить отсутствие фона/щелчков при выключенном источнике.
