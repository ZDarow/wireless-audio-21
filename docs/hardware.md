# Аппаратная часть Wireless Audio 2.1

> Версия документа: 1.1 (10.08.2026). GPIO соответствуют дефолтам
> `config.example.env` / `config.example.h`. Платформа — ESP32-S3
> (см. ТЗ §5).

## 1. Состав системы

| Узел | Плата | Назначение |
|---|---|---|
| Мастер | ESP32-S3-N16R8 / ESP32-S3-DevKitC-1 | Приём Wi-Fi UDP PCM, DSP, раздача каналов, сабвуфер |
| Сателлит левый | ESP32-S3 mini / WROOM-1 | Приём левого канала, вывод на динамик |
| Сателлит правый | ESP32-S3 mini / WROOM-1 | Приём правого канала, вывод на динамик |

Роль и сторона задаются на этапе прошивки (см. `docs/architecture.md` §9).
В сателлитах допускается ESP32-WROOM-32E без PSRAM, если не требуется
сложная обработка (ТЗ §5.4).

## 2. Питание

- Мастер: 24 В → DC-DC 5 В (от шины RS-400W-24V) → ESP32-S3, OLED, энкодер
  (ТЗ §5.2). LC-фильтр по входу 5 В; цифровая и силовая земля — в одной точке.
- Сателлиты: 5 В или 12 В, усилитель класса D — отдельно от ESP32,
  общая земля обязательна.
- Суммарный ток: ESP32-S3 до ~500 мА (Wi-Fi активен). Усилители — по паспорту.

## 3. I2S-выход (аудио)

Каждый узел использует один I2S-канал в режиме master TX, моно
(`I2S_CHANNEL_FMT_ONLY_LEFT`), 16 бит, 48000 Гц.

| Сигнал | GPIO по умолчанию | Описание |
|---|---|---|
| BCK (bit clock) | **26** | тактовая частота битов |
| WS (word select) | **25** | переключение каналов L/R |
| DATA_OUT | **22** | аудиоданные (последовательный) |

> Внимание: GPIO 22 используется и для I2S DATA_OUT, и как OLED SCL
> (см. §5). Одновременно I2S и OLED на одном пине использовать нельзя —
> выберите разные пины в конфигурации.

### Подключение к ЦАП/усилителю

Типовая схема (например, PCM5102A или MAX98357A):

```
ESP32 GPIO26 (BCK)  →  ЦАП BCK
ESP32 GPIO25 (WS)   →  ЦАП LRCK
ESP32 GPIO22 (DIN)  →  ЦАП DIN
GND                 →  ЦАП GND
```

- **PCM5102A**: питание 3.3 В, выход на усилитель (например, PAM8403).
- **MAX98357A**: I2S-усилитель класса D, питание 5 В, выход напрямую на
  динамик. Пины: BCLK, LRC, DIN, VIN, GND.

## 4. Wi-Fi (мастер)

- Модуль: встроенный Wi-Fi 2.4 GHz ESP32-S3 (b/g/n). Bluetooth Classic/A2DP
  на S3 отсутствует — аудио приходит по Wi-Fi UDP PCM со смартфона (ТЗ §6).
- Режимы: AP_DIRECT (мастер создаёт точку доступа `Audio21-Master`,
  канал 6, 20 МГц) или STA (подключение к домашней сети) — см. конфиг.
- Power save Wi-Fi отключается (для стабильного аудиопотока).

## 5. Опционально (этап 4 — OLED и энкодер)

Пины зарезервированы в конфигурации, но в MVP не используются:

| Сигнал | GPIO по умолчанию | Модуль |
|---|---|---|
| OLED SDA | **21** | SSD1306 (I2C) |
| OLED SCL | **22** | SSD1306 (I2C) |
| ENC A | **32** | энкодер KY-040 |
| ENC B | **33** | энкодер KY-040 |
| ENC BTN | **34** | кнопка энкодера |

> GPIO 34 — вход-only (без подтяжки). GPIO 21/22 имеют аппаратные
> подтяжки (I2C). Конфликт I2S DATA_OUT (22) и OLED SCL (22) — см. §3.

## 6. Рекомендации по разводке

- Аудио-линии (BCK/WS/DIN) — короткие, экранированные от силовых.
- Питание усилителя — отдельно от ESP32, общая земля в одной точке
  (звезда), чтобы избежать фона 50 Гц.
- Развязка по питанию: керамика 100 нФ + электролит 100–470 мкФ у
  ESP32 и у усилителя.
- Антенна ESP32 — не ближе 1 см от металла и силовых проводов.

## 7. Проверка после сборки

1. `pio run -e master_s3_wifi -t upload` — прошить мастер.
2. `pio run -e satellite_s3_left -t upload` и `-e satellite_s3_right` — сателлиты.
3. `pio device monitor` — в консоли мастера `status`; у сателлитов
   `master_online: yes` при работающей передаче.
4. Web UI мастера: `http://<IP>/` (IP печатается при старте).
5. Проверить отсутствие фона/щелчков при выключенном источнике.
