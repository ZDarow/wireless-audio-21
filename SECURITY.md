## Сообщение об уязвимости

Если вы нашли уязвимость в безопасности, пожалуйста, не открывайте публичный issue. Сообщите о ней приватно через GitHub Security Advisories или напишите maintainers.

Мы постараемся ответить в течение 7 дней.

## Известные уязвимости (см. docs/REPO_AUDIT.md)

| ID | Описание | Статус |
|----|----------|--------|
| V1 | ESP-NOW broadcast/heartbeat не зашифрован (unicast зашифрован PMK/LMK) | Документировано |
| V2 | Per-device соль в NVS v5 не реализована | Планируется |
| V4 | UDP-аудио без аутентификации источника | Исправлено (HMAC-SHA256, ключ AUDIO_UDP_AUTH_KEY) |
| V5 | OTA без подписи образа | Исправлено (Ed25519, заголовок X-OTA-Signature) |
| S-1 | Дефолтный пароль AP | Исправлено (forced password change при первом запуске) |

## Меры безопасности, реализованные в проекте

- **Аутентификация UDP-аудио**: HMAC-SHA256, магия 0xA211, ключ `AUDIO_UDP_AUTH_KEY` (по умолчанию задан, не пустой)
- **Подпись OTA**: Ed25519 через mbedTLS, проверка перед `Update.end()`
- **Авторизация Web UI**: SHA-256(password + salt), PBKDF2-HMAC-SHA256 (10000 итераций), CSRF-токены, сессии с таймаутом 3600 с
- **Rate limit**: блокировка после 5 неудачных попыток входа (60 с), скан Wi-Fi не чаще 5 с
- **Доступ только из локальной подсети**: Web UI недоступен извне STA/AP сети
- **Forced password change**: Web UI блокируется 403 до смены дефолтного пароля AP
- **Security-заголовки**: CSP, X-Frame-Options: DENY, X-Content-Type-Options: nosniff
